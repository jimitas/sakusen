# 地味に助かる　作戦ボード

スポーツの作戦を立てるための戦術ボードアプリです。選手の配置や矢印を使った戦術図を簡単に作成でき、スクリーンショットでの保存も可能です。

![作戦ボード](https://img.shields.io/badge/Status-Live-brightgreen)
![Next.js](https://img.shields.io/badge/Built_with-Next.js-black)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🌐 デモ

[https://jimitas.github.io/sakusen/](https://jimitas.github.io/sakusen/)

## ✨ 特徴

- **直感的な操作**: ドラッグ&ドロップで選手や要素を配置
- **豊富な戦術要素**:
  - 赤・青の選手コマ（各10個）
  - 8方向の矢印
  - ボールアイコン
- **作戦テンプレート**: 12種類の定型作戦から選択可能
- **スクリーンショット機能**: 作成した戦術図を画像として保存
- **レスポンシブデザイン**: PC・タブレット・スマートフォンに対応
- **カスタマイズ可能**: コートとゴールの色をカスタマイズ済み

## 🏟️ 仕様

### コート
- **背景色**: 黄緑色（#9ACD32）
- **サイズ**: レスポンシブ対応（最大800px × 400px）
- **ライン**: 白色の境界線とフィールドライン

### ゴール
- **左ゴール**: 青色（#0064b3）
- **右ゴール**: 赤色（#e50011）

### 選手コマ
- **赤チーム**: 10個（番号1-10）
- **青チーム**: 10個（番号1-10）
- **サイズ**: レスポンシブ対応

## 🚀 使い方

1. **作戦選択**: ヘッダーのドロップダウンから作戦を選択
2. **選手配置**: 画面下の選手コマをドラッグしてコート上に配置
3. **矢印配置**: 8方向の矢印をドラッグして動きを表現
4. **ボール配置**: ボールアイコンをコート上に配置
5. **回転機能**: 「回転」ボタンで要素を回転
6. **保存**: スクリーンショットを撮って保存
